# Lab Analytics (vitrine)

> **Todos os dados deste repositorio sao ficticios**, gerados por um gerador deterministico (`dados.js`).
> Nao ha pacientes, medicos, laboratorios, resultados ou valores reais. O produto real nao esta aqui.

Metricas operacionais de um laboratorio de diagnostico sobre pedidos inventados: tempo de liberacao
(mediana e p90), percentual dentro do prazo por exame e receita mensal.

```bash
node cli.js
node --test
```
